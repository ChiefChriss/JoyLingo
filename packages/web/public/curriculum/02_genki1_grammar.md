# 02 — Genki I Grammar (げんき I · 第1〜12課)

> **Covers:** Lessons 1–12 of Genki I — all foundational Japanese grammar
> **JLPT:** N5 level
> **Prerequisite:** Kana literacy (hiragana + katakana)

---

## 📐 Lesson 1: XはYです — "X is Y"

### 1.1 Basic Sentence Pattern

```
N1 は N2 です。     N1 is N2.
```

| Pattern | Meaning | Example |
|---------|---------|---------|
| N1 は N2 です | Affirmative | わたしは がくせいです。(I am a student.) |
| N1 は N2 じゃないです | Negative | わたしは がくせいじゃないです。(I am not a student.) |
| N1 は N2 ですか | Question | あなたは がくせいですか。(Are you a student?) |

**Also valid negative:** N1 は N2 ではありません (more formal/written)

### 1.2 Particles Introduced

| Particle | Function | Example |
|----------|----------|---------|
| **は** (wa) | Topic marker — "as for X" | わたし**は**... |
| **か** | Question marker (end of sentence) | ...ですか。 |
| **の** | Possessive / "of" | わたし**の**なまえ (my name) |
| **も** | "also, too" (replaces は/が/を) | わたし**も**がくせいです。 |

### 1.3 Question Words

| Word | Meaning | Example |
|------|---------|---------|
| なに／なん | what | これは なんですか。(What is this?) |
| だれ | who | あのひとは だれですか。(Who is that person?) |
| なんさい／おいくつ | how old | なんさいですか。(How old are you?) |
| どこ | where | がっこうは どこですか。 |
| いつ | when | たんじょうびは いつですか。 |

### 1.4 Numbers (1–100)

| 1–10 | 11–20 | 10s |
|------|-------|-----|
| いち、に、さん、し/よん、ご、ろく、しち/なな、はち、きゅう/く、じゅう | じゅういち、じゅうに... | にじゅう(20)、さんじゅう(30)...ひゃく(100) |

**Age:** ～さい (いっさい for 1, はっさい for 8, じゅっさい for 10)

## 📐 Lesson 2: これ・それ・あれ — "This, That, That Over There"

### 2.1 Demonstratives (こそあど System)

| Prefix | こ (near speaker) | そ (near listener) | あ (far from both) | ど (question) |
|--------|-------------------|---------------------|---------------------|---------------|
| **～れ** (thing) | これ this | それ that | あれ that over there | どれ which |
| **～の** (+ noun) | このN this N | そのN that N | あのN that N over there | どのN which N |
| **～こ** (place) | ここ here | そこ there | あそこ over there | どこ where |
| **～ちら** (direction, polite) | こちら this way | そちら that way | あちら that way | どちら which way |

### 2.2 Key Patterns

```
これは N です。      This is N.
この N は ... です。  This N is ...
```

### 2.3 Sentence-Ending Particles

| Particle | Nuance | Example |
|----------|--------|---------|
| **ね** | Seeking agreement / "right?" | いいですね。(That's nice, isn't it?) |
| **よ** | Asserting / giving new info | これも たかいですよ。(This is expensive too, you know!) |

## 📐 Lesson 3: Verb Conjugation (る/う/Irregular) + Particles

### 3.1 The Three Verb Types

| Type | How to Identify | Examples |
|------|----------------|----------|
| **る-verbs** (一段) | End in ～iru/～eru AND the stem is the same minus る | たべる (eat), みる (see), おきる (get up) |
| **う-verbs** (五段) | Everything else: ～u, ～ku, ～su, ～tsu, ～nu, ～bu, ～mu, ～ru (non-iru/eru) | のむ (drink), いく (go), はなす (speak) |
| **Irregular** | Only two! | する (do), くる (come) |

**Tricky う-verbs** that end in ～iru/～eru: かえる (return), きる (cut), しる (know), はいる (enter), はしる (run)

### 3.2 ます Form (Polite Present/Future)

| Type | Stem | + ます | Meaning |
|------|------|--------|---------|
| る-verb: たべる | たべ | たべます | eat / will eat |
| う-verb: のむ | のみ | のみます | drink / will drink |
| irreg: する | し | します | do / will do |
| irreg: くる | き | きます | come / will come |

**ます conjugation:**

| Form | Pattern | Example (たべる) |
|------|---------|-----------------|
| Present affirmative | stem + ます | たべます (eat) |
| Present negative | stem + ません | たべません (don't eat) |
| Past affirmative | stem + ました | たべました (ate) |
| Past negative | stem + ませんでした | たべませんでした (didn't eat) |
| Volitional | stem + ましょう | たべましょう (let's eat) |

### 3.3 Particles in Lesson 3

| Particle | Function | Example |
|----------|----------|---------|
| **を** (o) | Direct object marker | コーヒー**を**のみます。(I drink coffee.) |
| **で** | Place of action / means | としょかん**で**べんきょうします。(Study at the library.) |
| **に** (time) | Specific time | じゅういちじ**に**ねます。(Go to bed at 11.) |
| **に** (goal) | Direction/destination | うち**に**かえります。(Return home.) |
| **へ** (e) | Direction (〜へ = toward) | にほん**へ**いきます。(Go to Japan.) |

**Note:** に and へ are often interchangeable for direction, but に is more precise.

### 3.4 Time Expressions

| When | No に needed |
|------|-------------|
| Relative time | きょう (today), あした (tomorrow), きのう (yesterday), まいあさ (every morning), こんばん (tonight) |
| Specific time | 〜じ (o'clock), 〜ようび (day of week), 〜がつ〜にち (date) — **use に** |

## 📐 Lesson 4: ある・いる (Existence), Location, Past Tense

### 4.1 あります (inanimate) / います (animate)

| | Thing (ある) | Being (いる) |
|---|-------------|-------------|
| Affirmative | あります (there is) | います (there is) |
| Negative | ありません | いません |

### 4.2 Location Patterns

```
N1 は N2 (location) に あります／います。
  N1 is at N2.

N2 (location) に N1 が あります／います。
  At N2, there is N1.
```

**Examples:**
- ほんは つくえの うえに あります。(The book is on the desk.)
- へやに ねこが います。(There is a cat in the room.)

**Position words:** うえ (on/above), した (under), まえ (in front), うしろ (behind), なか (inside), そと (outside), となり (next to), ちかく (near), あいだ (between), みぎ (right), ひだり (left)

### 4.3 Past Tense of です

| | Affirmative | Negative |
|---|-------------|----------|
| Present | です | じゃないです / じゃありません |
| Past | でした | じゃなかったです / じゃありませんでした |

### 4.4 Particles

| Particle | Function | Example |
|----------|----------|---------|
| **と** | "and" (exhaustive list), "with" | えんぴつ**と**けしゴム (pencil and eraser) |
| **も** | "also" — replaces は/が/を | わたし**も**いきます。 |
| **～時間** (じかん) | Duration | にじかん (2 hours) |
| **～ぐらい** | Approximately | さんじかんぐらい (about 3 hours) |

## 📐 Lesson 5: Adjectives (い/な) + すき/きらい

### 5.1 Two Types of Adjectives

| Type | Ending | Examples |
|------|--------|----------|
| **い-adjectives** | End in ～い | たかい (expensive), おもしろい (interesting), いい (good) |
| **な-adjectives** | Need な before nouns | しずか[な] (quiet), げんき[な] (healthy), すき[な] (liked) |

### 5.2 い-Adjective Conjugation

| Form | Pattern (drop い) | たかい (expensive) |
|------|------------------|---------------------|
| Present aff. | ～いです | たかいです (is expensive) |
| Present neg. | ～くないです | たかくないです (is not expensive) |
| Past aff. | ～かったです | たかかったです (was expensive) |
| Past neg. | ～くなかったです | たかくなかったです (was not expensive) |

**Exception:** いい (good) → よくないです, よかったです, よくなかったです

### 5.3 な-Adjective Conjugation

| Form | Pattern (drop な) | しずか[な] (quiet) |
|------|-------------------|---------------------|
| Present aff. | ～です | しずかです |
| Present neg. | ～じゃないです | しずかじゃないです |
| Past aff. | ～でした | しずかでした |
| Past neg. | ～じゃなかったです | しずかじゃなかったです |

### 5.4 すき(な) / きらい(な) — Likes and Dislikes

```
N が すきです。     I like N.
N が きらいです。   I dislike N.
N が だいすきです。 I love N.
N が だいきらいです。 I hate N.
```

**Note:** The object of すき/きらい takes **が**, not を. These are な-adjectives, not verbs in Japanese.

### 5.5 ～ましょう／～ましょうか

| Pattern | Meaning | Usage |
|---------|---------|-------|
| ～ましょう | "Let's ~" | たべましょう。(Let's eat.) |
| ～ましょうか | "Shall I ~?" (offering) | てつだいましょうか。(Shall I help?) |

## 📐 Lesson 6: て-Form — Requests, Permission, Prohibition

### 6.1 How to Form て-Form

| Verb Type | Rule | Dictionary → て-Form |
|-----------|------|---------------------|
| **る-verbs** | Drop る, add て | たべる → たべて |
| **う-verbs: ～う、～つ、～る** | → って | かう → かって, まつ → まって, とる → とって |
| **う-verbs: ～む、～ぶ、～ぬ** | → んで | のむ → のんで, あそぶ → あそんで, しぬ → しんで |
| **う-verbs: ～く** | → いて | かく → かいて |
| **う-verbs: ～ぐ** | → いで | およぐ → およいで |
| **う-verbs: ～す** | → して | はなす → はなして |
| **Irregular** | | する → して, くる → きて |
| **Exception** | | いく → いって (not いいて!) |

### 6.2 て-Form Patterns

| Pattern | Meaning | Example |
|---------|---------|---------|
| ～てください | Please do ~ | まってください。(Please wait.) |
| ～てもいいです | May I / is it okay to ~ | はいってもいいですか。(May I come in?) |
| ～てはいけません | Must not / cannot ~ | ここでたべてはいけません。(You must not eat here.) |
| ～てから | After doing ~ (sequence) | しゅくだいをしてから、テレビをみます。 |
| ～ている | Progressive / state (L7) | べんきょうしています。(I am studying.) |

### 6.3 Joining Sentences with て-Form

The て-form can connect predicates (like "and"):

- きょうとしょかんに いって、べんきょうします。(I'll go to the library and study.)
- The tense of the final predicate determines the tense of the whole sequence.

## 📐 Lesson 7: ～ている (Progressive, Habitual, Resultant State)

### 7.1 ている Meanings

| Meaning | Example | Translation |
|---------|---------|-------------|
| **Progressive** (action in progress) | いま べんきょうしています。 | I am studying now. |
| **Habitual** (regular action) | まいにち にほんごを べんきょうしています。 | I study Japanese every day. |
| **Resultant state** (change that persists) | けっこんしています。 | I am married. |

### 7.2 Verbs That Show Resultant State

These verbs express a **change** — the ている form means the result is still in effect:

| Verb | Meaning | ている = |
|------|---------|----------|
| すわる | to sit | is seated |
| たつ | to stand | is standing |
| けっこんする | to get married | is married |
| しる | to come to know | knows |
| もつ | to hold/take | has, possesses |
| いく／くる | to go/come | has gone/come (and is still there) |

### 7.3 ～に いく (Going to Do Something)

```
Verb stem (ます without ます) + に いく／くる／かえる
  Go / come / return to do ~
```

- ひるごはんを たべに いきます。(I go to eat lunch.)
- にほんへ にほんごを べんきょうしに きました。(I came to Japan to study Japanese.)

### 7.4 Counting People

| # | Counter |
|---|---------|
| 1 | ひとり |
| 2 | ふたり |
| 3 | さんにん |
| 4+ | よにん、ごにん... |

## 📐 Lesson 8: Short Forms (Present) + と思う・と言う

### 8.1 What Are Short Forms?

Short forms (普通形 / ふつうけい) are the **casual/dictionary** forms — used with friends, in quoted speech, and in many grammar patterns.

### 8.2 Short Form Conjugation (Present)

| | Verb (る/う/irreg) | い-adj | な-adj | Noun |
|---|-------------------|--------|--------|------|
| **Aff. (polite → short)** | たべます → たべる | たかいです → たかい | しずかです → しずかだ | がくせいです → がくせいだ |
| **Neg. (polite → short)** | たべません → たべない | たかくないです → たかくない | しずかじゃないです → しずかじゃない | がくせいじゃないです → がくせいじゃない |

**Irregular short forms:**
- する → しない (negative)
- くる → こない (negative)
- ある → ない (negative)
- いい → よくない (negative)

### 8.3 ～と おもう — "I Think That..."

```
Short form + と おもいます。    I think that...
Short form + と おもって います。 I think (ongoing belief)
```

- たなかさんは くる**と**おもいます。(I think Tanaka will come.)
- にほんごは むずかしい**と**おもいます。(I think Japanese is difficult.)

**Note:** When the short form ends in だ (な-adj/noun affirmative), drop the だ:
- しずかだとおもいます ✓ (NOT しずかだだとおもいます)

### 8.4 ～と いう — "Say That..."

```
Short form + と いいます。    Say that...
```

- たなかさんは あした やすむ**と**いいました。(Tanaka said he's taking tomorrow off.)

### 8.5 ～ないで ください — "Please Don't..."

```
Verb negative short form + で ください
```

- ここで しゃしんを とら**ないで**ください。(Please don't take photos here.)

## 📐 Lesson 9: Short Forms (Past) + ～たことがある

### 9.1 Past Short Forms

| | Verb | い-adj | な-adj | Noun |
|---|------|--------|--------|------|
| **Affirmative** | た form (same as て form with た/だ) | ～かった | ～だった | ～だった |
| **Negative** | ～なかった | ～くなかった | ～じゃなかった | ～じゃなかった |

### 9.2 た-Form Formation (Same Rules as て-Form!)

| て → た | Verb → た-form |
|---------|----------------|
| ～て → ～た | たべて → たべた |
| ～って → ～った | かって → かった |
| ～んで → ～んだ | のんで → のんだ |
| ～いて → ～いた | かいて → かいた |
| ～いで → ～いだ | およいで → およいだ |
| ～して → ～した | はなして → はなした |

### 9.3 ～た ことが ある — "Have the Experience of..."

```
Verb た-form + ことが あります／ありません
  Have (ever) done / have never done
```

- にほんへ いったことが あります。(I've been to Japan.)
- すしを たべたことが ありません。(I've never eaten sushi.)

### 9.4 Qualifying Nouns with Verbs/Adjectives

```
[Short form predicate] + Noun
```

The predicate directly modifies the noun — no "that/who/which" word needed:
- きのう かった ほん (the book I bought yesterday)
- わたしが よく いく レストラン (the restaurant I often go to)

## 📐 Lesson 10: Comparison + つもり + なる

### 10.1 Comparison Patterns

| Pattern | Meaning | Example |
|---------|---------|---------|
| A は B より [adj] | A is [more adj] than B | にほんは アメリカより ちいさいです。 |
| A と B と どちらが [adj] ですか | Which is more [adj], A or B? | コーヒーと おちゃと どちらが すきですか。 |
| A の ほうが [adj] | A is more [adj] | にほんごの ほうが むずかしいです。 |
| [Category] で なにが いちばん [adj] ですか | What is the most [adj] in [category]? | にほんりょうりで なにが いちばん おいしいですか。 |
| A が いちばん [adj] | A is the most [adj] | すしが いちばん おいしいです。 |

**より with negative:** A は B ほど [neg-adj] = A is not as [adj] as B

### 10.2 ～つもりだ — "Intend to / Plan to"

```
Verb short form (present) + つもりです
Verb short form negative + つもりです
```

- あした とうきょうへ いくつもりです。(I plan to go to Tokyo tomorrow.)
- たばこを すわないつもりです。(I intend not to smoke.)

### 10.3 Adjective + なる — "Become"

| Adj Type | Pattern | Example |
|----------|---------|---------|
| い-adj | ～くなる | あたたかくなりました。(It became warm.) |
| な-adj | ～になる | げんきになりました。(I became well.) |
| Noun | N になる | せんせいになりました。(I became a teacher.) |

### 10.4 どこかに／どこにも

| Pattern | Meaning |
|---------|---------|
| どこか**に** いく (positive) | Go somewhere |
| どこ**にも** いかない (negative) | Not go anywhere |
| なにか**を** たべる | Eat something |
| なに**も** たべない | Not eat anything |

## 📐 Lesson 11: ～たい, ～たり, ～ことがある, Noun A や Noun B

### 11.1 ～たい — "Want to Do"

```
Verb stem (ます without ます) + たい
```
Conjugates like an い-adjective:
- すしを たべたいです。(I want to eat sushi.)
- たべたくないです。(I don't want to eat.)
- たべたかったです。(I wanted to eat.)

**Note:** The object marker を often changes to が with ～たい:
- すし**が** たべたい。(I want to eat sushi.) — が emphasizes the object of desire

### 11.2 ～たり～たり する — "Do Things Like A and B"

```
Verb た-form + り、Verb た-form + り する
```

- どようびは えいがを みたり、かいものをしたり します。
  (On Saturdays, I do things like watch movies and go shopping.)

**With nouns/adjectives:**
- きょうしつは あつかったり、さむかったり します。(The classroom is sometimes hot, sometimes cold.)

### 11.3 ～たことがある — "Have Done ~" (Review from L9)

```
Verb た-form + ことがある／ない
```

### 11.4 Noun A や Noun B (など) — "A and B (and such)"

**や** is used for **inexhaustive** lists (unlike と which is exhaustive):
- にほんごの クラスで えんぴつ**や**ノート**など**が いります。(In Japanese class, you need pencils, notebooks, and stuff like that.)

## 📐 Lesson 12: ～んです, ～すぎる, ～ばかり, ～ので

### 12.1 ～んです — Explanatory "It is that..."

The **explanatory の** shortens to **ん** in speech. Adds explanatory/emphasis tone.

```
Short form + んです／のです
```

| Context | Example | Nuance |
|---------|---------|--------|
| Giving explanation | あたまが いたいんです。(It's that my head hurts.) | Explaining why you're not going |
| Seeking explanation | どこへ いくんですか。(Where is it that you're going?) | Seeking more context |
| Soft assertion | わたしも いきたいんです！(It's that I want to go too!) | Emphasizing |

**Rules:**
- Verb/い-adj short form + んです
- な-adj/Noun: ～な + んです (e.g., しずかなんです, がくせいなんです)

### 12.2 ～すぎる — "Too much / Excessively"

| Type | Pattern | Example |
|------|---------|---------|
| Verb stem | stem + すぎる | たべ**すぎ**ました。(I ate too much.) |
| い-adj (drop い) | stem + すぎる | たか**すぎ**ます。(It's too expensive.) |
| な-adj (drop な) | stem + すぎる | しずか**すぎ**ます。(It's too quiet.) |

### 12.3 ～ほうが いい — "It's Better to..."

```
Verb た-form + ほうが いいです    (should do / it's better to do)
Verb ない-form + ほうが いいです  (should not / it's better not to)
```

- はやく ねたほうが いいですよ。(You should go to bed early.)
- たばこを すわないほうが いいです。(You shouldn't smoke / It's better not to smoke.)

### 12.4 ～ので — "Because..." (Reason/Cause)

```
Short form + ので、[result]
```

**ので** is softer/politer than から. Use when giving reasons politely.
- あした しけんが ある**ので**、きょう べんきょうします。(Because there's an exam tomorrow, I'll study today.)

**な-adj/Noun:** ～なので (e.g., しずかなので, やすみなので)

### 12.5 ～なければ いけない／～なきゃ いけない — "Must / Have to"

```
Verb negative short form (drop い) + ければいけない
  → ～なければいけません (must do)
  → ～なきゃいけません (colloquial)
```

- まいにち べんきょうし**なければいけません**。(I must study every day.)
- いか**なきゃ**！(I gotta go!)

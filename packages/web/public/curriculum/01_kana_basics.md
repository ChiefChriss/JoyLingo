# 01 — Kana Basics (仮名の基礎)

> **Hiragana ひらがな + Katakana カタカナ = Kana**
> These are the two phonetic syllabaries of Japanese. Master them before moving on.

---

## 📖 The Japanese Writing System

Japanese uses **three scripts** simultaneously:

| Script | Used For | Count | Example |
|--------|----------|-------|---------|
| **Hiragana** ひらがな | Native words, grammar endings, particles | 46 basic + diacritics | わたし (watashi) |
| **Katakana** カタカナ | Loan words, foreign names, emphasis, onomatopoeia | 46 basic + diacritics | アメリカ (America) |
| **Kanji** 漢字 | Content words (nouns, verb/adjective stems) | 2,136 常用 (regular use) | 日本語 (nihongo) |

**Every sound in Japanese is one of these syllables.** There is no alphabet — only syllables.

---

## 🗣️ Pronunciation Quick Guide

Japanese has **5 vowel sounds**, always pure (no diphthongs):

| Vowel | IPA | Like English... |
|-------|-----|-----------------|
| **あ a** | [a] | f**a**ther |
| **い i** | [i] | s**ee** |
| **う u** | [ɯ] | f**oo**d (but unrounded lips) |
| **え e** | [e] | b**e**t |
| **お o** | [o] | g**o** |

**Key rules:**
- Vowels can be **short** (1 beat) or **long** (2 beats): おばさん (aunt) ≠ おばあさん (grandmother)
- **Double consonants** (っ / ッ) = pause for 1 beat: がっこう (gakkou) — hold the k
- **ん / ン** is its own beat and never starts a word
- **Pitch accent** matters: はし can be 箸 (chopsticks, high→low) or 橋 (bridge, low→high)
- **R-sound** is a tap/flap — between English R, L, and D

### Special Notes
- **は** is read "wa" when used as the topic particle: わたしは (watashi wa)
- **へ** is read "e" when used as the direction particle: とうきょうへ (Tōkyō e)
- **を** is used ONLY as the object particle (read "o")
- **ぢ** and **づ** are rare; usually じ and ず are used instead

### Katakana-Specific Features
- **Long vowels** use ー (chōonpu): コーヒー (kōhī = coffee)
- **Small vowels** (ァィゥェォ) for foreign sounds: ファ (fa), ティ (ti), ディ (di)
- **ヴ** (vu) for V sound: ヴァイオリン (violin)

## ✍️ Stroke Order Principles

1. **Top to bottom**
2. **Left to right**
3. **Horizontal before vertical** when they cross
4. **Outside before inside** (but bottom stroke last: 口 is 丨𠃍一)
5. **Center before sides** for symmetrical characters

> **Practice tip:** Write 10 of each kana daily. Use grid paper. Say the sound aloud as you write. This builds muscle memory + sound association simultaneously.
